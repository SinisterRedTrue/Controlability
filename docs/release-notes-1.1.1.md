# Controlability 1.1.1 — Settings Refined

A clearer Settings page puts everyday controls, game targets, and controller mappings within easier reach.

## What's changed

- Redesigned Settings with compact cards and a section index for General, Input, Hiding, Appearance, Target games, Keyboard mappings, Controller reference, Advanced, and About.
- Added compact keyboard and controller mapping previews with expandable full mapping lists.
- Refined switches, buttons, labels, and controller symbols for a more consistent Settings interface.
- Added an expandable third-party licences panel and a clearly labelled uninstall section.
- Added rendering checks for the Settings overview at desktop and smaller window sizes, expandable mappings, and licence visibility. The checks also verify that browsing these controls does not save settings.

## Download and upgrade

Download **Controlability-Setup-1.1.1.exe** and run it to install or upgrade. The Windows x64 installer includes .NET and can install ViGEmBus and HidHide when needed. Existing settings and profiles are retained.

The accompanying **Controlability-Setup-1.1.1.exe.sha256** contains the installer's SHA-256 checksum.

## Validation

Built with the full Release test suite and the self-contained Windows x64 installer pipeline.
